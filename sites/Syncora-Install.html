Product Sign in

Install and use Syncora

One product, three ways in: the Windows app, a phone icon on the same Wi-Fi, or localhost while you develop.

Windows app iPhone / Android Development Sign in

Windows computer

1. Get the Syncora folder

Receive the shared project folder. Do not include a development .env file.

2. Open the app file

Double-click this file in the folder you received:

Open-Syncora.cmd

3. First launch

Install Python 3.11+ if needed, then open the file again.

Download Python 3.11+

4. Sign in

admin@syncora.dev ChangeMe123!

Or open http://localhost:8600/login when developing.

iPhone and Android

Home-screen install

  1. Leave Open-Syncora.cmd running on the computer.
  2. Open %LOCALAPPDATA%\Syncora\phone-url.txt and copy the phone address.
  3. Open it in Safari or Chrome on the same Wi-Fi.
  4. iPhone: Share → Add to Home Screen. Android: Add to Home screen / Install app.

Development

Localhost

npm run frontend npm run backend

Then open http://localhost:8600/
