Install

A web app, installed directly

Syncora installs from the browser onto a computer or a phone. Nothing else to download, and no extra software to set up.

Computer

Chrome or Edge installs Syncora onto the computer. It then opens in its own window.

  1. Choose Install the app on this page.
  2. On the Syncora page, choose Install app.
  3. Launch it from the desktop, Dock, or Start menu, then sign in.

Phone

The same address becomes a home-screen app. There is no store and no extra download.

  1. Choose Install the app, and open that page in Safari or Chrome.
  2. iPhone: Share, then Add to Home Screen.
  3. Android: browser menu, then Install app. Then sign in.
